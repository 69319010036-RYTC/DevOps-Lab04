# DevOps-Lab04

## คำอธิบายโครงการ

โครงการนี้เป็นหน้า Landing Page สำหรับระบบแจ้งซ่อมและบริการสนับสนุนด้าน IT ชื่อ FixIT Support โดยออกแบบให้ผู้ใช้งานสามารถเข้าถึงบริการแจ้งปัญหาอุปกรณ์ ระบบ หรือเครือข่ายได้ง่ายและรวดเร็ว

เว็บไซต์นี้มีการจัดโครงสร้างหน้าเพจแบบสวยงามและใช้งานง่าย โดยเน้นความเป็นมืออาชีพของทีม IT พร้อมทั้งแสดงข้อมูลสำคัญ เช่น

- บริการช่วยเหลือด้านเทคโนโลยีสารสนเทศ
- การแจ้งปัญหาและขอรับการซ่อมแซม
- สถิติการให้บริการและประสิทธิภาพของทีม
- ปุ่มเพื่อเข้าสู่กระบวนการแจ้งซ่อมหรือติดต่อทีม support

## วัตถุประสงค์

เพื่อแสดงภาพรวมของบริการช่วยเหลือเทคโนโลยีให้กับผู้ใช้งานและสร้างประสบการณ์ที่ดีในการติดต่อกับฝ่าย IT รวมถึงช่วยลดเวลาในการแจ้งปัญหาและเพิ่มความสะดวกในการดูแลระบบภายในองค์กร

## เทคโนโลยีที่ใช้

- HTML
- CSS
- Responsive Web Design

## ลักษณะเด่น

- โทนสีหลักเป็นสีเหลืองและขาวที่สะท้อนถึงความน่าเชื่อถือและความเป็นมืออาชีพ
- Layout แบบสวยงาม เหมาะสำหรับเว็บไซต์บริการ
- รองรับการแสดงผลบนอุปกรณ์หลากหลายขนาด
- เหมาะสำหรับใช้เป็นหน้าให้บริการหรือแนะนำระบบ IT Support ในโครงการฝึกปฏิบัติ DevOps
